# Validation

Use fictional input only. Paste a quoted item label above Amount/Price and confirm it does not auto-create an Amount product. Review a quoted category source-use choice and confirm its name has no Markdown wrapper. Verify the existing quantity fixture unchanged.

Paste `Item,Price,Notes` with a quoted comma-containing name and doubled quotes in notes. Review through existing column selectors, save and inspect names, prices and details. Repeat with headerless tab-separated rows, empty cells, Markdown escaped pipes, repeated headers and nearby contact notes. Unclosed quotes, multiline quoted cells and unequal delimiter-bearing rows must remain intact Text.

Choose a real supported raster picture with normal and missing MIME metadata. Check stored bytes, editor thumbnail, menu-file preview and exported file. Simulate a byte-read failure and confirm an actionable refusal and reusable picker without document mutation.

Run focused Vitest suites, then PowerShell `npm run verify` with a ten-minute
timeout budget and progress polling. On Android, ordinary picture selection must
open the system document picker. Select a PNG, cancel replacement, inspect preview
and exported embedded bytes, then cold-launch and check persistence. The SM_T700
passed this check on 2026-10-05 with test.7; see
[native evidence](../../docs/research/2026-10-05-native-picture-picker.md).
